# Frontend (React + Vite) — g_dechet

This folder contains a minimal React + Vite skeleton with a registration page that calls the Django backend API.

Quick start (Node.js must be installed):

```powershell
cd frontend
npm install
npm run dev
```

The dev server will run on port 5173 by default. Edit `src/api.js` to point to the backend API URL (default: http://localhost:8001/api/).
